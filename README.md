# Student Performance & Academic Analytics
Beginner-friendly Data Analytics project using 1,200 synthetic student-subject records.

## Tools
Python, Pandas, Matplotlib, Excel

## Run
pip install pandas matplotlib openpyxl
python analysis.py

## Questions answered
- Which subjects perform best?
- Which schools have the highest average scores?
- Which study methods have higher average scores?
- What is the grade distribution?
- How do study hours relate to final scores?

All data is synthetic and intended for educational/project-submission purposes.
